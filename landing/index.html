One key to
find anything.

Press ⌘K or /. Titles, words inside documents, topics and commands, in one list.

  • Searches the text Paperless read from each scan
  • Recent records before you type
  • Opens beside the list, or in a sheet on a phone
  • Every action has a key

If you don’t like something, fork it.

~/code
$ gh repo fork majicmaj/papermint --clone
✓ Cloned papermint into ./papermint
$ cd papermint && npm ci
✓ packages installed
$ npm run demo
